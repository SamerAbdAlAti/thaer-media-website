# موقع Thaer Media

موقع ثابت مبني بـ [Astro](https://astro.build)، بنفس تصميم ومحتوى وروابط الموقع الحالي [thaerdesigner.com](https://thaerdesigner.com)، لكن بأداء أعلى بكثير. العربي على نفس الروابط، والإنجليزي تحت `/en/`. يُنشر تلقائياً على GitHub Pages.

| الصفحة | العربي | الإنجليزي |
| --- | --- | --- |
| الرئيسية | `/` | `/en/` |
| التواصل | `/contact/` | `/en/contact/` |
| الدورة | `/socialmedia.courses1/` | `/en/socialmedia.courses1/` |
| معرض السوشيال ميديا | `/work.social/` | `/en/work.social/` |
| معرض الهوية البصرية | `/work.brand/` | `/en/work.brand/` |
| معرض المطبوعات | `/work.print/` | `/en/work.print/` |
| معرض نتائج الحملات | `/work.ads/` | `/en/work.ads/` |
| لوحة التحكم | `/admin/` | |

## لوحة التحكم: `/admin/`

افتح `رابط-الموقع/admin/`. اللوحة غير مربوطة بأي رابط في الموقع، ومخفية عن محركات البحث.

1. **عدّل** النصوص والصور من الأقسام الجانبية: الرئيسية، سلايدر الدورة، الخدمات، المعارض الأربعة، صفحة التواصل، صفحة الدورة، وصفحة 404. كل نص له خانة عربي وخانة إنجليزي، والقوائم فيها إضافة وحذف وترتيب.
2. **الصور:** اختر الصورة كما هي، حتى لو كانت من الكاميرا. اللوحة تصغّرها على جهازك (حتى 2400px وبصيغة WebP)، وتعطيها اسماً مناسباً، وتكتب مسارها في البيانات تلقائياً.
3. **حفظ ونشر:** اللوحة تفحص البيانات أولاً بنفس قواعد الموقع، ثم تعطيك ثلاث خطوات:
   1. تنزيل الصور الجديدة، وزر يفتح صفحة الرفع على GitHub في المجلد الصحيح.
   2. نسخ البيانات (JSON).
   3. زر يفتح ملف `src/data/site.json` على GitHub: حدّد الكل، والصق، ثم Commit.

**ارفع الصور قبل لصق البيانات.** إذا انعكس الترتيب، البناء يفشل والموقع يبقى كما هو، حتى تصل الصور.

**المسودة تُحفظ تلقائياً في المتصفح.**

**الأمان:** اللوحة لا تستطيع تغيير أي شيء بنفسها. التعديل يصل للموقع فقط عندما يرفعه شخص لديه صلاحية على ريبو GitHub.

## تعديل المحتوى يدوياً

كل نصوص الموقع ومسارات الصور في ملف واحد: [`src/data/site.json`](src/data/site.json).

- كل نص له نسختين `{ "ar": "...", "en": "..." }`.
- العناوين ذات الجزء الملوّن مقسومة إلى `kicker` (الجزء الملوّن) و`title`.
- الترقيم (01، 02...) وعدد الأعمال في المعارض يُحسبان تلقائياً.
- رقم واتساب والإيميل مكتوبان مرة واحدة في `contact`. كل الأزرار والنماذج والفوتر تأخذ منهما.

**إذا كان في خطأ بالملف**، البناء يتوقف ويطبع قائمة بالمشاكل وأماكنها، والموقع المنشور يبقى كما هو.

## الصور

ضع الصورة داخل `src/assets/` واكتب مسارها في `site.json` بدون `src/assets/`.

| المجلد | المحتوى |
| --- | --- |
| `gallery/social/` | تصاميم السوشيال ميديا (طولية 4:5 أو مربعة، تُعرض كاملة بدون قص) |
| `gallery/identity/` | الهويات البصرية |
| `gallery/print/covers/` و`gallery/print/artwork/` | المطبوعات: صورة العمل في مكانه + التصميم نفسه الذي يظهر عند التكبير |
| `gallery/ads/` | لقطات تقارير الحملات (تُعرض داخل شاشة) |
| `ad-slides/` | شرائح سلايدر الدورة (1440×480، نسخة لكل لغة) |
| `work-covers/ar/` و`work-covers/en/` | أغلفة بطاقات "أعمالنا" |
| `images/` | صور الواجهة، والمدرب، وقسم "من نحن" (لكل صورة شخصية نسخة للوضع الفاتح) |

**لا تحتاج تصغير الصور قبل رفعها.** عند كل بناء تتحول كل صورة تلقائياً إلى AVIF وWebP بعدة مقاسات، والمتصفح يحمّل المقاس المناسب لشاشة الزائر فقط. صور المشاركة على السوشيال (`public/previews/`) والأيقونات (`public/`) تُستخدم كما هي.

## النشر على GitHub Pages

1. ارفع المشروع على GitHub (فرع `main`).
2. من إعدادات الريبو: **Settings → Pages → Source: GitHub Actions**.
3. كل push على `main` يبني الموقع وينشره تلقائياً ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)). الصور التي سبق تحويلها تُحفظ مؤقتاً، فالنشر يحوّل الجديدة فقط.
4. **لنقل thaerdesigner.com إلى هذه النسخة:** من Settings → Pages أضف الدومين في Custom domain، وحدّث سجلات DNS عند مزوّد الدومين حسب تعليمات GitHub. الروابط العربية مطابقة للموقع الحالي، فلا شيء ينكسر.
